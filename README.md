# Vrinda Store Sales Analysis

## About the Project

This project is based on the analysis of Vrinda Store sales data using Microsoft Excel.

The main purpose of this project is to understand sales and order performance and find useful patterns in the data. The analysis covers customer details, sales channels, order status, gender, age groups and state-wise sales.

## Objective

The project was created to:

* Analyze sales and order data
* Understand customer purchasing patterns
* Compare sales between men and women
* Analyze sales based on age groups
* Find the top-performing states
* Compare different sales channels
* Analyze different order statuses
* Create a dashboard to present the analysis

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Excel Formulas
* Data Cleaning
* Data Visualization

## Analysis Performed

### Sales and Orders

Analyzed sales and order data to understand the overall performance of the store.

### Men and Women Analysis

Compared sales and orders between male and female customers.

### Age and Gender Analysis

Analyzed customer data based on age groups and gender to understand purchasing patterns.

### Top 5 States

Analyzed state-wise sales and identified the top-performing states.

### Order Status

Analyzed different order statuses to understand the overall order performance.

### Sales Channels

Compared different sales channels to see which channels contributed to sales.

## Dashboard

An Excel dashboard was created to present the important findings from the analysis in an easy-to-understand format.

The dashboard uses charts, Pivot Tables and slicers to make the analysis easier to explore.
